# 🎙️ AI Voice Authenticity & Similarity Analyzer

A desktop application built with Python, Tkinter, Resemblyzer, and Hugging Face audio models that analyzes voice recordings for both speaker similarity and AI-generated speech detection.

The system combines speaker embeddings, machine learning, and deepfake audio detection models to compare multiple audio files, visualize relationships between voices, and estimate the likelihood that a recording was generated by AI.

## Features

### Voice Similarity Analysis
- Extracts speaker embeddings using Resemblyzer
- Compares multiple voice samples
- Calculates similarity scores between speakers
- Identifies the closest matching voice automatically
- Supports WAV, MP3, and MP4 audio files

### AI Voice Detection
Multi-model deepfake detection pipeline using Hugging Face models:
- MelodyMachine/Deepfake-audio-detection-V2
- Jianf-MS/Audio-Deepfake-Detection-wav2vec2
- aumaree/ai-audio-detector
- Ensemble scoring across multiple detectors
- AI probability confidence scoring
- Human vs. synthetic voice classification

### Custom Model Training
- Folder-based dataset training workflow
- Logistic Regression classifier trained on:
  - Resemblyzer speaker embeddings
  - Deepfake detector outputs
  - Spectral audio features
- User-trainable with custom AI and human voice datasets

### Audio Processing Pipeline
- Automatic audio normalization
- Silence trimming
- MP3/MP4 → WAV conversion using FFmpeg
- 16kHz mono preprocessing for model consistency

### Visualization
- UMAP projection of speaker embeddings
- Visual clustering of voice samples
- Interactive GUI results dashboard
- Confidence scores and similarity metrics

## Workflow

1. Select audio files through the GUI
2. Convert and preprocess recordings
3. Generate speaker embeddings
4. Compute voice similarity scores
5. Run deepfake detection models
6. Apply trained logistic regression classifier
7. Display AI confidence and similarity metrics
8. Visualize results using UMAP
